# Revisão cruzada — backend (fase 9)

- Revisor: arquiteto · Data: 2026-11-19 · Alvo: `backend/` vs `docs/api/contracts.md` e `ADR-001`
- Execução: `mvn -q -B test` → **40 testes, 0 falhas**. Também subi a API local (`target/classes`, porta 18081, `APP_TRUST_PROXY=true`, `-Xmx256m`) e testei com `curl`. Os achados marcados com **[verificado]** foram reproduzidos.
- Decisões derivadas: `docs/architecture/ADR-002-abuse-protection-hardening.md`.

## Pontos positivos
- As camadas estão corretas: `ProjectController → ProjectService → ProjectCatalog` e `ContactController → ContactService → RateLimiter/SpamGuard/ContactSink`. Controllers não têm lógica de negócio.
- Todos os DTOs são `record`. As listas são copiadas para imutáveis (`List.copyOf`, `Map.copyOf`).
- Dentro do MVC, todos os erros saem como ProblemDetail (`type`, `title`, `status`, `detail`, `instance`). O `errors` só aparece em 400 de validação, e 404 de rota desconhecida também vira ProblemDetail.
- O CORS é restritivo: origens vêm de env, lista vazia nega tudo, `allowCredentials(false)` e `Retry-After` está exposto. **[verificado]** O 429 sai com `Access-Control-Allow-Origin` e `Access-Control-Expose-Headers: Retry-After`.
- `APP_TRUST_PROXY` **está ligado corretamente**: `application.yml:29` → `${APP_TRUST_PROXY:false}` → `@Value("${app.trust-proxy:false}")` em `ClientIpResolver.java:18`. **[verificado]** Com `true`, o XFF é usado.
- O rate limiter é thread-safe: a mutação do `ArrayDeque` acontece só dentro de `compute`/`computeIfPresent`, que são atômicos por chave no `ConcurrentHashMap`. O `Retry-After` está correto.
- PII: o corpo e o assunto nunca são logados, o e-mail é mascarado e há sanitização contra log forging.
- Dockerfile: multi-stage, roda como usuário não-root `app`, usa `exec` (sinais chegam à JVM), `MaxRAMPercentage` e `ExitOnOutOfMemoryError`.
- Validar dentro do `ContactService` **funciona para o objetivo declarado**: corpos JSON válidos com campos inválidos contam no limite. A abordagem tem um furo (M1), e a forma idiomática de cumprir o mesmo objetivo é um `HandlerInterceptor` (ADR-002 §4).
